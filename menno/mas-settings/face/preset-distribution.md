# 顔シェイプキープリセット配布ガイド

M. Avatar Settingで作った顔プリセットを販売・無料配布するときに守るルールです。プリセットの作り方は[クイックスタート](/menno/mas-settings/face/preset-quickstart/)を見てください。

::: warning 注意
このガイドの内容は参考情報です。配布前には必ず最新の[Mennoアバター利用規約](https://drive.google.com/file/d/1K8AcjlYHFfJ4cFcJvBvvwei79qwlbqFx/view)を確認してください。
:::

## 必ず守るルール

1. **配布できるのは `.asset` ファイルのみです。** `Assets/emudotto/Menno/Resources/Face_Presets/` 内にある `.asset` ファイルだけを配布できます。
2. **プリセット以外のデータは含められません。** Mennoアバターのモデルデータ（.fbx）やテクスチャなど、プリセットファイル以外のデータを含めて配布することは固く禁止します。
3. **販売できます。** 作成したプリセットは、営利・非営利を問わず自由に配布・販売できます。
4. **利用者がMennoアバター本体を別途購入済みであることを必須条件にしてください。** 配布ページの概要欄などに、次の文を必ず記載してください。

   ```text
   本データは #Menno3D 専用のプリセットです。
   使用には別途販売されているMennoアバター本体が必要です。
   ```

5. **利用は自己責任です。** 配布されたプリセットの利用は自己責任です。作成者およびemudottoは、プリセットの利用によって生じたいかなる問題についても責任を負いません。

## おすすめ（任意）

- UnityPackage形式で配布すると、利用者が導入しやすくなります。
- 利用者の利便性のため、プリセットに次の情報を設定することを推奨します。

| 項目 | 内容 |
|---|---|
| 名前 | プリセットの内容がわかる名前（例：`Menno_Face_Preset_Calm`） |
| 説明 | プリセットの特徴や注意点など |
| 作者 | あなたの名前やブランド名 |
