# 顔の設定

肌・目・耳の見た目と、目や口などの形（ブレンドシェイプ）を変えられます。

![顔の設定UI](/assets/images/face_setting.png)

## 使い方

1. M. Avatar Settingウィンドウを開く
2. Mennoアバターを選択する
3. 「顔の設定」セクションを展開する
4. 項目を選ぶか、カテゴリを展開してスライダーを動かす

## 基本設定

| 項目 | 選択肢 | 補足 |
|---|---|---|
| 肌の色 | 標準色 / 褐色 / 灰色 / カスタム | カスタムでは顔テクスチャと体ベーステクスチャを自由に設定 |
| テクスチャの種類 | 細目 / 丸目 | 細目はMenno、丸目はEmmelieの目のテクスチャ |
| 目のテクスチャ | 標準色 / 黄色 / 赤色 / 黒色 / 白色 / カスタム | カスタムでは目のテクスチャを自由に設定（テクスチャの種類は無効になる） |
| 耳の形状 | 標準 / エルフ1 / エルフ2 / エルフ3 / エルフ4 | |
| 目のくま | なし / 黒くま / 赤くま / くま線 | 目の下のくま |

## ブレンドシェイプ

カテゴリを展開すると、スライダーが表示されます。

| カテゴリ | 主な項目 |
|---|---|
| 目（EYE） | 目の開き、目の大きさ、瞳の大きさ、視線方向（上下左右） |
| 眉毛（EYEBROW） | 上下位置、角度、太さ |
| まつげ（EYELASH） | 長さ、角度、密度 |
| 口（MOUTH） | 開き具合、口角の上下、口の幅、唇の厚さ |
| 鼻（NOSE） | 鼻の高さ、鼻の幅、小鼻の形状 |
| 耳（EAR） | 耳の大きさ、耳の角度、エルフ耳の形状（エルフ耳選択時） |
| あご（JAW） | あごの長さ、あごの幅、尖り具合 |
| 歯（TEETH） | 歯の露出具合、歯の形状 |

ブレンドシェイプ名は、ウィンドウ右上の言語切り替えボタン（日本語/英語）に合わせて切り替わります。

::: warning 注意
- 顔の設定はMennoアバターにのみ適用されます。
- ブレンドシェイプ同士が干渉することがあります。思わぬ結果になったら、関連する設定も確認してください。
:::

## リセット

「リセット」ボタンを押し、確認ダイアログで「はい」を選ぶと、顔の設定がすべて初期状態に戻ります。
