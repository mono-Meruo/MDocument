# 顔シェイプキープリセット（詳細ガイド）

ボタンの働き、プリセットを重ねたときの計算、保存先、トラブルの対処を調べられます。基本の手順は[クイックスタート](/menno/mas-settings/face/preset-quickstart/)にあります。

![プリセット機能UI](/assets/images/preset_ui.png)

## 画面の項目

| 項目 | 働き |
|---|---|
| 「保存」ボタン | 入力した名前で、現在のブレンドシェイプ設定を保存する |
| 「強度」スライダー | プリセットを0〜100%の強さで適用する。すぐ顔に反映される |
| フォルダボタン（「保存済みプリセット:」の横） | 保存フォルダをプロジェクトウィンドウで開く |
| 「X」ボタン | 確認のあと、そのプリセットを削除する |

## 適用のしくみ

- 適用しても現在の設定を完全には上書きせず、強度で効き具合を調整できます。
- 複数のプリセットを同時に適用すると値が加算されます（例：smile 0.5 + 0.3 = 0.8）。
- 値は1.0を超えません（例：0.7 + 0.6 = 1.3ではなく1.0）。
- 後から適用したプリセットが優先されます。強度0%のプリセットは無視されます。
- リアルタイムで変更中の値が最優先されます。

## 保存されるファイル

プリセットは `.asset` ファイルとして次のフォルダに保存されます。中身はプリセット名、各ブレンドシェイプの値（0.0〜1.0）、作成日時です。

```
Assets/emudotto/Menno/Resources/Face_Presets/
```

プリセットはプロジェクトごとに保存され、Unityを再起動しても残ります。

## 他のプロジェクトで使う

プリセットファイルは他のプロジェクトにコピーして使えます。販売・配布する場合は[配布ガイド](/menno/mas-settings/face/preset-distribution/)のルールに従ってください。

### 書き出す

1. プロジェクトウィンドウで `Face_Presets` フォルダを開きます。
2. 共有したいプリセットファイルを選択します。
3. 右クリックして「Export Package」を選択します。

### 読み込む

1. 受け取ったファイルをプロジェクトにドラッグ＆ドロップします。
2. ファイルを `Face_Presets` フォルダに置きます。書き出し時のフォルダが `Face_Presets` なら自動でここに入ります。
3. M. Avatar Settingウィンドウを開き直します。

## 困ったとき

| 症状 | 原因 | 対処 |
|---|---|---|
| 保存されない | ファイルの書き込み権限がない | Unityプロジェクトフォルダの権限を確認する |
| 適用されない | ブレンドシェイプ名が変更された | プリセットを作り直すか、.assetファイルを手動で編集する |
| 強度が効かない | 他のスクリプトがブレンドシェイプを制御している | 競合するスクリプトを無効化するか、実行順序を調整する |
