# 髪の毛の設定

髪の色と、ブレンドシェイプによる髪型を変えられます。

![髪の毛の設定UI](/assets/images/hair_settings.png)

## 使い方

1. M. Avatar Settingウィンドウを開く
2. Mennoアバターを選択する
3. 「髪の毛の設定」セクションを展開する
4. 色ボタンを押すか、カテゴリを展開してスライダーを動かす

## 設定項目

| 項目 | 選択肢 | 補足 |
|---|---|---|
| 髪の色 | デフォルト / 灰色 / 黒色 | ボタンを押すとすぐ変わる |
| 髪型 | カテゴリごとのスライダー | 髪のブレンドシェイプを調整 |

表示言語（日本語/英語）は、ウィンドウ右上の言語切り替えボタンで変えられます。

::: warning 注意
極端な設定値は、見た目や物理演算に影響することがあります。
:::

## リセット

「リセット」ボタンを押し、確認ダイアログで「はい」を選ぶと、髪の毛の設定がすべて初期状態に戻ります。
