# アイテムの設定

衣装と、VRChat上で出し入れできるトグルアイテムの使用・初期表示・色を設定できます。

![アイテムの設定UI](/assets/images/item_settings.png)

## 使い方

1. M. Avatar Settingウィンドウを開く
2. Mennoアバターを選択する
3. 「衣装の設定」セクションを展開する
4. 使いたい衣装の横のチェックボックスをオンにする

## 衣装

| 項目 | 内容 |
|---|---|
| チェックボックス | その衣装を使う |
| 初期状態 | オンにすると、アバターのロード時から表示。複数の衣装で有効にできる |
| 色ボタン | 標準色 / 白色。すべての衣装の色がまとめて変わる |

## トグルアイテム

対象は Pan（フライパン）、Xondle、Mokia（携帯電話）の3つです。

| 項目 | 内容 |
|---|---|
| 有効/無効 | アイテムを使うかどうか |
| 音声効果 | 切り替え時に効果音を鳴らすかどうか |
| 初期状態 | アバターのロード時に表示するかどうか |

アイテム名や説明は、ウィンドウ右上の言語切り替えボタン（日本語/英語）に合わせて切り替わります。

## リセット

「リセット」ボタンを押し、確認ダイアログで「はい」を選ぶと、衣装とトグルアイテムの設定がすべて初期状態に戻ります。

## 読み込み元のファイル

| 対象 | 場所 |
|---|---|
| 衣装プレハブ | `Assets/emudotto/Menno/Animation/ModularAvatar/Costume` |
| トグルアイテムのプレハブ | `Assets/emudotto/Menno/Prefab/ToggleProps.prefab` |
| 衣装のマテリアル | `Assets/emudotto/Menno/Materials/Menno_Wear.mat` |
