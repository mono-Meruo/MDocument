# シェイプキー一覧

Menno のシェイプキー（合計 885 個）の名前と用途を調べられます。表情や体型を調整するときの参照に使ってください。

## 使い方

1. Unity の Inspector でモデルを選びます。
2. SkinnedMeshRenderer コンポーネントを開きます。
3. 「Blend Shapes」で各シェイプキーのスライダーを動かします（0 = 効果なし、100 = 最大）。

複数のシェイプキーを組み合わせて、独自の表情や体型を作れます。

## 顔（855 個）

機能を持つシェイプキーは 697 個です（Empty と区切り用を除く）。各カテゴリに、両目用のほか左（`_L`）・右（`_R`）用があり、左右非対称の表情も作れます。

表情用（EYE・MOUTH・EYEBROW など）を形の調整に、調整用（`_Option` 系。例: EYE_Option、MOUTH_Option、JAW_Option）を表情アニメーションに使うこともできます。

### Perfect-Sync（実験中）

より自然な表情同期のためのセットです。眉（内側上・外側上・下など）、目（上下左右・まばたき・細目など）、頬（膨らみ・引き締めなど）、鼻（しわ寄せなど）、あご（開閉・前後左右など）、口のさまざまな形を制御できます。今後のアップデートで変更される可能性があります。

## 体（30 個）

体の部位ごとの縮小に使います。対象は首、肩、腕、手、指、胸、背中、腰、脚、足などです。

## 髪（50 個）

Hair_Bangs オブジェクトに含まれます（Empty を除く機能的なシェイプキー）。番号付きのシェイプキー（01、02 など）は髪の一束ずつに対応し、特定の束だけを動かしたり形を変えたりできます。

## Empty シェイプキー

Unity でシェイプキーを途中に追加すると、既存の順番がずれて設定済みの値と合わなくなることがあります。これを防ぐため、空のシェイプキー（Empty）をあらかじめ多数用意し、アップデート時にはここへ新機能を追加しています。

## 表情アニメーションを直す

::: warning 注意
目や口などを大きく変えると、元の形を前提に作られたデフォルトの表情アニメーションが崩れることがあります（まばたきが不自然になる、発話がずれる、など）。その場合は次の手順でアニメーションを調整してください。
:::

1. Menno アバターのルートオブジェクトを選びます。
2. Animator コンポーネントに「Menno_Layer_FX.controller」（表情アニメーションのデフォルト設定入り）を設定します。
3. `Window > Animation > Animation` で Animation ウィンドウを開きます。
4. シーン内で Menno アバターを選びます。
5. Animation ウィンドウで既存の表情アニメーションを選びます。
6. 変更したシェイプキーのキーフレームをクリックし、数値を編集します。
7. VRChat Gesture Manager などで表情の動きを確認し、必要なら微調整します。
