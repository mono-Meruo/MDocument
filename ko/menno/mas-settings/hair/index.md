# 머리카락 설정

헤어 색상과 블렌드 셰이프를 통해 헤어 스타일을 변경할 수 있습니다.

![머리카락 설정 UI](/assets/images/hair_settings.png)

## 사용 방법

1. M. Avatar Setting 창을 엽니다.
2. Menno 아바타를 선택합니다.
3. 「머리카락 설정」 섹션을 펼칩니다.
4. 색상 버튼을 누르거나 카테고리를 펼치고 슬라이더를 조정합니다.

## 설정 항목

| 항목 | 선택지 | 비고 |
|---|---|---|
| 헤어 색상 | 기본값 / 회색 / 검은색 | 버튼을 클릭하면 즉시 변경됩니다. |
| 헤어 스타일 | 카테고리별 슬라이더 | 헤어의 블렌드 셰이프를 조정합니다. |

표시 언어(일본어/영어)는 창 오른쪽 상단의 언어 전환 버튼으로 변경할 수 있습니다.

::: warning 주의
과도한 설정 값은 외관이나 물리 연산에 영향을 줄 수 있습니다.
:::

## 리셋

「리셋」 버튼을 누르고 확인 대화상자에서 「예」를 선택하면 모든 머리카락 설정이 기본 상태로 변경됩니다.
