# 얼굴 설정

피부, 눈, 귀의 외관과 눈이나 입 등의 형태(블렌드쉐이프)를 변경할 수 있습니다.

![顔の設定UI](/assets/images/face_setting.png)

## 사용법

1. M. Avatar Setting 창을 엽니다
2. Menno 아바타를 선택합니다
3. "얼굴 설정" 섹션을 확장합니다
4. 항목을 선택하거나 카테고리를 확장하여 슬라이더를 조절합니다

## 기본 설정

| 항목 | 선택지 | 참고 |
|---|---|---|
| 피부 색상 | 기본색 / 갈색 / 회색 / 커스텀 | 커스텀에서는 얼굴 텍스처와 바디 베이스 텍스처를 자유롭게 설정할 수 있습니다 |
| 텍스처 종류 | 세밀 눈 / 둥근 눈 | 세밀 눈은 Menno, 둥근 눈은 Emmelie의 눈 텍스처입니다 |
| 눈 텍스처 | 기본색 / 노란색 / 빨간색 / 검은색 / 흰색 / 커스텀 | 커스텀에서는 눈 텍스처를 자유롭게 설정할 수 있습니다(텍스처 종류 설정이 비활성화됩니다) |
| 귀 형태 | 기본 / 엘프 1 / 엘프 2 / 엘프 3 / 엘프 4 | |
| 눈 다크서클 | 없음 / 검은색 / 붉은색 / 선 타입 | 눈 밑의 그늘 |

## 블렌드쉐이프

카테고리를 확장하면 슬라이더가 표시됩니다.

| 카테고리 | 주요 항목 |
|---|---|
| 눈(EYE) | 눈 뜨기 정도, 눈 크기, 동공 크기, 시선 방향(위아래좌우) |
| 눈썹(EYEBROW) | 위아래 위치, 각도, 두께 |
| 속눈썹(EYELASH) | 길이, 각도, 밀도 |
| 입(MOUTH) | 열림 정도, 입꼬리 위아래, 입 너비, 입술 두께 |
| 코(NOSE) | 코 높이, 코 너비, 콧살 형태 |
| 귀(EAR) | 귀 크기, 귀 각도, 엘프 귀 형태(엘프 귀 선택 시) |
| 턱(JAW) | 턱 길이, 턱 너비, 뾰족한 정도 |
| 치아(TEETH) | 이 노출 정도, 치아 형태 |

블렌드쉐이프 이름은 창 우측 상단의 언어 전환 버튼(일본어/영어)에 맞춰 함께 변경됩니다.

::: warning 주의
- 얼굴 설정은 Menno 아바타에만 적용됩니다.
- 블렌드쉐이프 간에 간섭이 발생할 수 있습니다. 의도하지 않은 결과가 나타나면 관련 설정도 함께 확인하십시오.
:::
