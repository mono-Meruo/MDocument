# 얼굴 블렌드 셰이프 프리셋 (퀵 스타트)

조정된 얼굴 형상을 프리셋으로 저장하여 슬라이더로 언제든지 불러올 수 있습니다. 각 버튼과 저장 위치의 상세 내용은 [자세한 가이드](/ko/menno/mas-settings/face/preset-guide/)를 참조하세요.

![프리셋 기능 UI](/assets/images/preset_ui.png)

## 프리셋 저장하기

1. 얼굴 설정에서 블렌드 셰이프를 원하는 형태로 조정합니다.
2. “셰이프 키 프리셋” 섹션에 프리셋 이름을 입력합니다. 초기값은 `Menno_Face_Preset_01` 과 같은 이름입니다. “아이”, “성인”, “어린 얼굴” 등 알기 쉬운 이름으로 변경할 수 있습니다.
3. “저장” 버튼을 클릭합니다.

## 프리셋 적용하기

1. “저장된 프리셋” 목록에서 사용할 프리셋을 찾습니다.
2. 해당 프리셋의 “강도” 슬라이더를 조절합니다. 얼굴이 즉시 변형됩니다.

| 강도 | 결과 |
|---|---|
| 0% | 적용하지 않음 |
| 50% | 절반 강도로 적용 |
| 100% | 완전히 적용 |

![assets](/assets/images/preset_assets_slider2.gif)

여러 프리셋의 강도를 동시에 높이면 혼합된 얼굴을 만들 수 있습니다 (예: “아이” 50%, “성인” 30%).

![assets](/assets/images/preset_assets_slider.gif)
