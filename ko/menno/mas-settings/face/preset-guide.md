# 얼굴 쉐입 키 프리셋 (상세 가이드)

버튼의 동작, 프리셋 중첩 시 계산 방식, 저장 위치 및 문제 해결 방법을 확인할 수 있습니다. 기본 절차는 [빠른 시작](/ko/menno/mas-settings/face/preset-quickstart/)에서 확인하세요.

![프리셋 기능 UI](/assets/images/preset_ui.png)

## 화면 항목

| 항목 | 동작 |
|---|---|
| “저장” 버튼 | 입력한 이름으로 현재 블렌드셰이프 설정을 저장합니다. |
| “강도” 슬라이더 | 프리셋을 0~100% 강도로 적용합니다. 얼굴에 즉시 반영됩니다. |
| 폴더 버튼 (“저장된 프리셋:” 옆) | 저장 폴더를 프로젝트 창에서 엽니다. |
| “X” 버튼 | 확인 후 해당 프리셋을 삭제합니다. |

## 적용 방식

- 적용해도 현재 설정이 완전히 덮어쓰기되지 않으며, 강도를 통해 적용 정도를 조정할 수 있습니다.
- 여러 프리셋을 동시에 적용하면 값이 합산됩니다 (예: smile 0.5 + 0.3 = 0.8).
- 값은 1.0을 초과하지 않습니다 (예: 0.7 + 0.6 = 1.3이 아닌 1.0).
- 나중에 적용한 프리셋이 우선 적용됩니다. 강도 0%의 프리셋은 무시됩니다.
- 실시간으로 변경 중인 값이 가장 우선합니다.

## 저장되는 파일

프리셋은 `.asset` 파일 형식으로 다음 폴더에 저장됩니다. 파일 내용에는 프리셋 이름, 각 블렌드셰이프의 값(0.0~1.0), 생성 일시가 포함됩니다.

```
Assets/emudotto/Menno/Resources/Face_Presets/
```

프리셋은 프로젝트별로 저장되며, Unity를 재시작해도 유지됩니다.

## 다른 프로젝트에서 사용하기

프리셋 파일은 다른 프로젝트로 복사하여 사용할 수 있습니다. 판매 또는 배포할 경우 [배포 가이드](/ko/menno/mas-settings/face/preset-distribution/)의 규칙을 따르세요.

### 내보내기

1. 프로젝트 창에서 `Face_Presets` 폴더를 엽니다.
2. 공유할 프리셋 파일을 선택합니다.
3. 오른쪽 클릭하여 `Export Package` 를 선택합니다.

### 가져오기

1. 받은 파일을 프로젝트에 드래그 앤 드롭합니다.
2. 파일을 `Face_Presets` 폴더에 배치합니다. 내보낼 때의 폴더가 `Face_Presets` 라면 자동으로 해당 폴더로 이동됩니다.
3. M. Avatar Setting 창을 다시 엽니다.

## 문제 해결

| 증상 | 원인 | 해결 방법 |
|---|---|---|
| 저장되지 않음 | 파일 쓰기 권한 없음 | Unity 프로젝트 폴더의 권한을 확인합니다. |
| 적용되지 않음 | 블렌드셰이프 이름이 변경됨 | 프리셋을 다시 생성하거나 .asset 파일을 수동으로 편집합니다. |
| 강도가 반영 안 됨 | 다른 스크립트가 블렌드셰이프를 제어 중 | 충돌하는 스크립트를 비활성화하거나 실행 순서를 조정합니다. |
