# 아이템 설정

의상과 VRChat에서 꺼내거나 넣을 수 있는 토글 아이템의 사용 여부, 초기 표시 상태 및 색상을 설정할 수 있습니다.

![아이템 설정 UI](/assets/images/item_settings.png)

## 사용 방법

1. M. Avatar Setting 창을 엽니다.
2. Menno 아바타를 선택합니다.
3. 의상 설정 섹션을 펼칩니다.
4. 원하는 의상 옆 체크박스를 활성화합니다.

## 의상

| 항목 | 내용 |
|---|---|
| 체크박스 | 해당 의상 사용 여부 |
| 초기 상태 | 활성화 시 아바타 로드 시 표시됨. 여러 의상을 동시에 활성화할 수 있음 |
| 색상 버튼 | 기본색 / 흰색. 모든 의상의 색상이 일괄 변경됨 |

## 토글 아이템

대상은 Pan(프라이팬), Xondle, Mokia(휴대전화) 3종입니다.

| 항목 | 내용 |
|---|---|
| 활성화/비활성화 | 아이템 사용 여부 |
| 효과음 | 전환 시 효과음 재생 여부 |
| 초기 상태 | 아바타 로드 시 표시 여부 |

아이템 이름 및 설명은 창 오른쪽 상단의 언어 전환 버튼(일본어/영어)에 맞춰 함께 변경됩니다.

## 리셋

'리셋' 버튼을 클릭하고 확인 대화상자에서 '예'를 선택하면, 의상 및 토글 아이템 설정이 모두 초기 상태로 돌아갑니다.
