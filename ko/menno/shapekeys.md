# 쉐입 키 목록

Menno 의 쉐입 키(총 885 개) 이름과 용도를 확인하세요. 표정이나 체형을 조정할 때 참고 자료로 사용하십시오.

## 사용 방법

1. Unity 의 Inspector 에서 모델을 선택합니다.
2. SkinnedMeshRenderer 컴포넌트를 엽니다.
3. “Blend Shapes”에서 각 쉐입 키의 슬라이더를 조정합니다(0 = 효과 없음, 100 = 최대).

여러 쉐입 키를 조합하여 나만의 표정이나 체형을 만들 수 있습니다.

표정용(EYE·MOUTH·EYEBROW 등)을 형태 조정에, 조정용(`_Option` 계열. 예: EYE_Option, MOUTH_Option, JAW_Option)을 표정 애니메이션에 사용하는 것도 가능합니다.

### Perfect-Sync(실험 중)

더 자연스러운 표정 동기화를 위한 세트입니다. 눈썹(안쪽 위·바깥쪽 위·아래 등), 눈(상하좌우·깜빡임·눈뜨기 등), 볼(볼륨업·타이트닝 등), 코(주름 생성 등), 턱(개폐·전후좌우 등), 입의 다양한 형태를 제어할 수 있습니다. 향후 업데이트에서 변경될 수 있습니다.

## 몸(30 개)

몸 부위별 축소에 사용합니다. 대상은 목, 어깨, 팔, 손, 손가락, 가슴, 등, 허리, 다리, 발 등입니다.

## 머리(50 개)

## Empty 쉐입 키

Unity 에서 쉐입 키를 중간에 추가하면 기존 순서가 어긋나 설정된 값과 일치하지 않을 수 있습니다. 이를 방지하기 위해 빈 쉐입 키(Empty)를 다수 미리 준비해 두었으며, 업데이트 시 이곳에 신규 기능을 추가하고 있습니다.

## 표정 애니메이션 수정

::: warning 주의
눈이나 입 등을 크게 변경하면 원본 형태를 기준으로 제작된 기본 표정 애니메이션이 깨질 수 있습니다(깜빡임이 부자연스러워짐, 발화가 어긋남 등). 이 경우 다음 절차에 따라 애니메이션을 조정하십시오.
:::

1. Menno 아바타의 루트 객체를 선택합니다.
2. Animator 컴포넌트에 “Menno_Layer_FX.controller”(표정 애니메이션 기본 설정 포함)를 설정합니다.
3. `Window > Animation > Animation`에서 Animation 창을 엽니다.
4. 씬 내에서 Menno 아바타를 선택합니다.
5. Animation 창에서 기존 표정 애니메이션을 선택합니다.
6. 변경한 쉐입 키의 키프레임을 클릭하고 수치를 편집합니다.
7. VRChat Gesture Manager 등으로 표정 움직임을 확인하고, 필요시 미세 조정합니다.
