# 头发设置

可调整发色，并通过混合形状更改发型。

![头发设置 UI](/assets/images/hair_settings.png)

## 使用方法

1. 打开 M. Avatar Setting 窗口
2. 选择 Menno 虚拟形象
3. 展开“头发设置”区块
4. 点击颜色按钮，或展开分类并拖动滑块

## 设置项

| 参数 | 选项 | 说明 |
|---|---|---|
| 发色 | 默认 / 灰色 / 黑色 | 点击按钮即可立即生效 |
| 发型 | 各分类下的滑块 | 调整头发混合形状 |

可通过窗口右上角的语言切换按钮更改显示语言（日文/英文）。

::: warning
极端设置值可能会影响外观或物理演算。
:::

## 重置

点击“重置”按钮并在确认对话框中选择“是”，即可将所有头发设置恢复为初始状态。
