# 面部形状键预设（详细指南）

了解按钮功能、预设叠加时的计算方式、保存位置以及故障排除方法。基本操作请参阅[快速入门](/zh/menno/mas-settings/face/preset-quickstart/)。

![预设功能 UI](/assets/images/preset_ui.png)

## 界面项目

| 项目 | 功能 |
|---|---|
| 「保存」按钮 | 以输入的名称保存当前的混合形状设置 |
| 「强度」滑块 | 以 0~100% 的强度应用预设。会立即反映到面部 |
| 文件夹按钮（「保存済みプリセット:」右侧） | 在项目窗口中打开保存文件夹 |
| 「X」按钮 | 确认后删除该预设 |

## 应用机制

- 应用时不会完全覆盖当前设置，可通过强度调整效果程度。
- 同时应用多个预设时，数值会相加（例如：smile 0.5 + 0.3 = 0.8）。
- 数值不会超过 1.0（例如：0.7 + 0.6 会截断为 1.0，而非 1.3）。
- 后应用的预设优先级更高。强度为 0% 的预设将被忽略。
- 实时修改的数值具有最高优先级。

## 保存的文件

预设以 `.asset` 文件格式保存到以下文件夹中。文件内容包含预设名称、各混合形状的数值（0.0~1.0）以及创建日期时间。

```
Assets/emudotto/Menno/Resources/Face_Presets/
```

预设按项目单独保存，重启 Unity 后依然保留。

## 在其他项目中使用

预设文件可复制到其他项目中直接使用。如需销售或分发，请遵守[分发指南](/zh/menno/mas-settings/face/preset-distribution/)中的规则。

### 导出

1. 在项目窗口中打开 `Face_Presets` 文件夹。
2. 选择要共享的预设文件。
3. 右键点击并选择“Export Package”。

### 导入

1. 将接收到的文件拖放到项目中。
2. 将文件放置到 `Face_Presets` 文件夹中。如果导出时的文件夹就是 `Face_Presets`，则会自动放入该位置。
3. 重新打开 M. Avatar Setting 窗口。

## 遇到问题时

| 症状 | 原因 | 解决方法 |
|---|---|---|
| 无法保存 | 文件无写入权限 | 检查 Unity 项目文件夹的权限 |
| 无法应用 | 混合形状名称已更改 | 重新创建预设，或手动编辑 .asset 文件 |
| 强度无效 | 其他脚本正在控制混合形状 | 禁用冲突的脚本，或调整执行顺序 |
