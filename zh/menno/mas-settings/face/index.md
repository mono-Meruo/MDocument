# 面部设置

可自定义皮肤、眼睛和耳朵的外观，以及眼睛、嘴巴等部位的形状（混合变形）。

![面部设置UI](/assets/images/face_setting.png)

## 使用方法

1. 打开 M. Avatar Setting 窗口
2. 选择 Menno 角色
3. 展开"面部设置"部分
4. 选择具体项目，或展开分类后拖动滑块

## 基本设置

| 项目 | 选项 | 说明 |
|---|---|---|
| 肤色 | 标准色 / 褐色 / 灰色 / 自定义 | 自定义可自由设置面部贴图与身体基础贴图 |
| 贴图类型 | 细眼 / 圆眼 | 细眼为 Menno 的眼部贴图，圆眼为 Emmelie 的眼部贴图 |
| 眼部贴图 | 标准色 / 黄色 / 红色 / 黑色 / 白色 / 自定义 | 自定义可自由设置眼部贴图（贴图类型将失效） |
| 耳朵形状 | 标准 / 精灵1 / 精灵2 / 精灵3 / 精灵4 | |
| 黑眼圈 | 无 / 黑眼圈 / 红眼圈 / 黑眼圈线 | 眼下的暗沉 |

## 混合变形

展开分类后，将显示相应滑块。

| 分类 | 主要项目 |
|---|---|
| 眼睛（EYE） | 眼睛开合度、眼睛大小、瞳孔大小、视线方向（上下左右） |
| 眉毛（EYEBROW） | 上下位置、角度、粗细 |
| 睫毛（EYELASH） | 长度、角度、密度 |
| 嘴巴（MOUTH） | 开合度、嘴角上下、嘴宽、唇厚 |
| 鼻子（NOSE） | 鼻梁高度、鼻宽、鼻翼形状 |
| 耳朵（EAR） | 耳朵大小、耳朵角度、精灵耳形状（选择精灵耳时） |
| 下巴（JAW） | 下巴长度、下巴宽度、尖锐程度 |
| 牙齿（TEETH） | 牙齿露出程度、牙齿形状 |

混合变形名称会跟随窗口右上角的语言切换按钮（日语/英语）进行切换。

::: warning 注意
- 面部设置仅适用于 Menno 角色。
- 各混合变形之间可能相互干扰。如果结果不符合预期，请同时检查相关设置。
:::

## 面部形状保留预设

可为当前的混合变形设置命名并保存，随后调整强度进行应用。同时支持多个预设叠加合成，也可将预设文件用于其他项目。

## 重置

点击"重置"按钮，在确认对话框中选择"是"，即可将所有面部设置恢复为初始状态。
